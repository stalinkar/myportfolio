Cutting Regression Runtime Without Cutting Coverage

APPROACH  Redesigned Jenkins pipelines for parallel execution, restructured test grouping and resource allocation, and layered gated nightly/PR builds.

APPROACH  Architected hybrid Selenium + Serenity BDD and Playwright + Serenity frameworks (Java/Cucumber), layering data-driven POM patterns with resilient wait/retry strategies.

Unifying API Validation Across Tools

APPROACH  Built a unified Rest Assured suite integrated into the Selenium regression bed, with lightweight Postman pre-request scripting reserved for edge cases.

How I Work

For teams and clients bringing me in to fix or build automation from the ground up — the same four-stage process every time, so nothing depends on tribal knowledge.

01

Discovery

Audit current coverage, release cadence, and risk areas. Talk to devs, PMs, and whoever owns the pain of a bad release.

02

Framework Design

Architect the layered stack — UI, BDD, API, CI, reporting — sized to the team's tech, skill level, and release goals. No one-size-fits-all templates.

03

Implementation

Build the suite, stabilize flaky legacy tests, wire it into CI/CD, and set coding standards and MR review checklists.

04

Handover & Mentoring

Document the framework, train the team to extend it themselves, and stay engaged for post-launch tuning — no black boxes left behind.
