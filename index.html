About Me

"Behind every seamless user experience is a tester who saw the bug before you did. Software quality is not just about testing—it’s about trust, automation, and enabling speed without compromise."

Hey there! I’m Stalin Kar, a Senior SDET / QA Automation Engineer with 11+ years of hands-on experience in functional and automation testing across UI and API layers. Whether it’s building robust UI frameworks or automating complex API workflows, I bring precision, performance, and passion to the testing table.
Currently at Broadridge Financial Solutions, I architect and maintain hybrid automation frameworks using Selenium + Serenity BDD (Java, Cucumber) and Playwright + Serenity, which grew automation coverage from 60% to 75% and cut manual regression effort by ~32 hours per release — accelerating release validation by 40%. Optimizing Jenkins pipelines with parallel runs brought a key module's full-regression runtime down from 9 hours to 6 hrs 45 mins (~35% faster), and data-driven/POM patterns with resilient wait-retry strategies lifted the consistent test pass-rate from 70% to 80%.
I’ve worked across fintech and insurance domains for over a decade, managing QA for mission-critical applications spanning asset management, transaction gateways, and claims processing. I thrive in Agile/SAFe teams, mentor junior testers, and bridge the gap between dev, QA, and business stakeholders.
Beyond the code, I’m an advocate for quality-first culture, agile practices, and mentoring teammates. I review and optimize team members’ automation code, set MR review checklists, and enforce coding standards to reduce review cycles and improve quality.
What sets me apart? I don’t just run tests—I engineer solutions. I’ve built reusable Java and Python libraries, custom VBA and SQL tools for test data management, and Rest Assured + Postman API suites that cut validation effort by ~50%.
🎯 Career-wise, I’m focused on growing into a QA leadership role where I can drive strategic automation and quality engineering initiatives across global teams.
💡 Fun fact: I’m a lifelong learner — always exploring new tools and techniques to enhance test automation and software quality.
